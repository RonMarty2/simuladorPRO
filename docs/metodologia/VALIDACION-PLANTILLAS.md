# Hoja de validación de las plantillas de la galería

Generada el 2026-10-23 desde el código. Las cifras de las plantillas son estimaciones del equipo, NO datos auditados de Bolivia. Esta hoja sirve para que una persona del rubro (dueño, gremio, docente) confirme o corrija los números que más mueven el resultado. Marca cada fila: OK, corregir (con el valor correcto) o no sé.

Cómo se usa: para cada plantilla, la persona del rubro mira la inversión total, los sueldos, los precios y los costos directos y dice si son creíbles para Bolivia hoy. Lo que corrija se cambia en `src/lib/plantillas.ts`.
